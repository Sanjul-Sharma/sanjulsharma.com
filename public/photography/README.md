# Photography

Drop your photo files right here in this folder — `.jpg`, `.jpeg`, `.png`,
`.webp`, `.avif`, or `.gif`.

They are picked up **automatically** and shown in the Freetime scroll wheel on
the site, sorted by filename. You don't need to edit any code.

- To control the order, prefix filenames with numbers: `01_beach.jpg`,
  `02_court.jpg`, `03_street.jpg`, …
- This README is ignored (it isn't an image).
- Tip: resize very large photos to ~2000px wide before adding, so the page
  stays fast.
